# Chunk SAD docs

Skill that chunks large documents into Software Architecture Document (SAD) or Technical Design Document (TDD) section markdown.

## Install

Copy `skills/chunk-sad` into `.cursor/skills/chunk-sad` (this project) or `~/.cursor/skills/chunk-sad` (all projects).

## Use

1. Attach or name the source files (markdown, plain text, Word, Excel). You can pass more than one.
2. Invoke `/chunk-sad`. Name another output folder if you do not want `docs/`.
3. Answer or skip the gap questions.
4. The 12 section files and `roadmap.md` land in the output folder.
